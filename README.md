## Deployment
This portfolio is hosted directly on GitHub Pages, leveraging the simplicity and reliability of static site hosting. Any updates pushed to the `main` branch are automatically deployed and reflected live.

**Live Demo**: [https://SOUGUR.github.io](https://SOUGUR.github.io)

## How to Run Locally
To view this portfolio on your local machine:

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/SOUGUR/SOUGUR.github.io.git
    ```
2.  **Navigate to the project directory**:
    ```bash
    cd SOUGUR.github.io
    ```
3.  **Open `index.html`**: Simply open the `index.html` file in your preferred web browser. No local server is required as it's a static site.
